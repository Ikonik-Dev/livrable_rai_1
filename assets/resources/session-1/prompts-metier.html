Exemples concrets et prêts à l'emploi — Direction, Administration, Formateurs

📋 Fiche pratique 🔴 RGPD inclus Référent IA : Référent IA
👑 Direction
1
Résumer une réunion d'équipe
Prompt à copier-coller
Tu es mon assistant de direction. Je vais te donner le contenu d'une réunion d'équipe (anonymisée, sans noms propres). Tu dois me fournir : 1. Un résumé en 5 bullet points maximum 2. Les décisions prises 3. Les actions à faire (sans noms, juste les rôles : "la direction", "l'équipe admin"…) 4. Le ton du résumé : professionnel, factuel Voici le contenu : [COLLER LE TEXTE ICI — sans noms ni données perso]
✅ Rappel RGPD : Anonymisez avant de coller (remplacez les noms par les fonctions)
2
Préparer un ordre du jour
Prompt à copier-coller
Crée un ordre du jour structuré pour une réunion de direction de 2h sur le thème : [VOTRE THÈME]. Inclure : horaires pour chaque point, animateur de chaque point (rôles génériques), objectif de chaque point. Format : tableau ou liste structurée. Ton : professionnel.
✅ 100% autorisé — aucune donnée personnelle impliquée
📂 Administration
3
Rédiger une lettre de relance
Prompt à copier-coller
Rédige une lettre de relance professionnelle et bienveillante pour un stagiaire qui n'a pas encore remis son devoir. Contraintes : - Ton : professionnel mais chaleureux, encourageant - Longueur : maximum 150 mots - Pas de données personnelles (utilise "[Prénom]" comme variable) - Inclure une date limite fictive "[Date limite]" - Signer de "[Votre nom]"
⚠️ Personnalisez ensuite en local — ne remettez pas les vrais noms dans ChatGPT
4
Créer un modèle de courrier type
Prompt à copier-coller
Crée un modèle de courrier officiel pour [TYPE DE COURRIER : convocation / accusé de réception / confirmation d'inscription…]. Format : courrier formel avec en-tête, corps, formule de politesse. Utilise des variables entre crochets pour les informations à personnaliser : [Nom], [Date], [Lieu], etc. Ton : formel, clair, professionnel.
✅ Excellent usage — les modèles avec variables ne contiennent aucune donnée réelle
🎓 Formateurs
5
Générer des questions de quiz
Prompt à copier-coller
Je suis formateur et j'ai besoin d'évaluer mes apprenants sur le module suivant : [NOM DU MODULE]. Crée 5 questions de quiz avec les caractéristiques suivantes : - Type : QCM (4 choix de réponse) - Niveau : débutant / intermédiaire / avancé [CHOISIR] - Inclure la bonne réponse (indiquée avec ✅) - Inclure une courte explication de la bonne réponse (1 phrase) - Format : numérotée, claire à lire
✅ 100% autorisé — contenu pédagogique générique, aucune donnée stagiaire
🔴 Mini-guide RGPD — Règles essentielles
⚠️
Ne jamais mettre dans ChatGPT : noms de stagiaires, emails, numéros de dossier, données médicales ou sociales, bulletins de notes
⚠️
Anonymisez toujours avant de coller un texte : remplacez les noms par les fonctions ("le formateur", "l'apprenant")
⚠️
ChatGPT peut stocker vos entrées — vérifiez les paramètres de confidentialité ou utilisez le mode temporaire

✅ OUI : brouillons, modèles, reformulations, quiz génériques, résumés anonymisés

❌ NON : données personnelles, dossiers stagiaires, informations médicales ou sociales

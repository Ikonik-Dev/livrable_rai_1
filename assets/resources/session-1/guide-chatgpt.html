Guide ChatGPT
pour Débutants

Tout ce qu'il faut savoir pour commencer à utiliser ChatGPT au travail

🤖 ChatGPT Niveau : Débutant absolu 🔴 RGPD inclus
1
Créer un compte ChatGPT (gratuit)

Vous aurez besoin d'un compte pour accéder à ChatGPT. La version gratuite est suffisante pour commencer.

📋 Étapes pour créer votre compte

  1. Allez sur https://chat.openai.com dans votre navigateur
  2. Cliquez sur "Sign up" (S'inscrire)
  3. Entrez votre adresse email professionnelle ou personnelle
  4. Créez un mot de passe sécurisé (au moins 12 caractères)
  5. Vérifiez votre email (cliquez sur le lien de confirmation)
  6. Acceptez les conditions d'utilisation
  7. C'est prêt ! Vous arrivez directement sur l'interface de chat
💡 Conseil : Vous pouvez aussi vous connecter via votre compte Google ou Microsoft si c'est plus simple.
⚠️ RGPD : Utilisez de préférence votre email professionnel, mais ne donnez jamais de données personnelles de stagiaires dans les conversations.
2
Comprendre l'interface

🖥️ Les éléments principaux

  • Zone de texte en bas : c'est là que vous tapez vos questions (appelées "prompts")
  • Panneau gauche : historique de vos conversations précédentes
  • Bouton "New chat" : démarrer une nouvelle conversation vierge
  • Zone centrale : affiche la conversation en cours (votre message + réponse de l'IA)
  • Bouton envoi : la flèche à droite de la zone de texte (ou touche Entrée)

⚙️ Paramètre important : désactiver l'entraînement du modèle

  1. Cliquez sur votre photo de profil (en haut à droite)
  2. Allez dans "Settings" (Paramètres)
  3. Cliquez sur "Data controls"
  4. Désactivez "Improve the model for everyone"
Pourquoi ? Cela empêche OpenAI d'utiliser vos conversations pour entraîner leur modèle. Recommandé pour un usage professionnel.
3
Écrire un bon prompt

Un "prompt" est le message que vous envoyez à ChatGPT. Plus votre prompt est précis, meilleure sera la réponse.

🏗️ La structure d'un bon prompt (méthode RTCF)
R — Rôle "Tu es un assistant administratif dans un organisme de formation…"
T — Tâche "Rédige une lettre de relance professionnelle…"
C — Contexte "…pour un stagiaire qui n'a pas remis son devoir depuis 2 semaines."
F — Format "Ton : bienveillant et professionnel. Maximum 150 mots."
❌ Prompt trop vague
"Écris une lettre"
Résultat : lettre générique inutilisable
⚠️ Prompt moyen
"Écris une lettre de relance pour un stagiaire"
Résultat : correct mais trop générique
✅ Bon prompt
"Tu es un assistant pédagogique. Rédige une lettre de relance bienveillante pour un stagiaire qui n'a pas remis son devoir d'action de développement. Ton : professionnel et encourageant. Maximum 150 mots. Utilise [Prénom] comme variable."
Résultat : lettre directement utilisable, à personnaliser
4
Astuces pour progresser

🔄 Améliorer une réponse insatisfaisante

  • "C'est trop long, raccourcis à 100 mots"
  • "Reformule ça de façon plus formelle"
  • "Donne-moi 3 autres versions différentes"
  • "Ajoute un paragraphe sur [sujet]"

📝 Demander des formats spécifiques

  • "Mets le résultat sous forme de tableau"
  • "Crée une liste à puces"
  • "Format : email formel avec objet et corps"
  • "Numérote chaque étape"

⚠️ Ce que ChatGPT ne sait pas faire

  • Accéder à Internet (sauf version payante avec plugins)
  • Connaître les actualités récentes (sa connaissance a une date limite)
  • Toujours avoir raison — il peut inventer des faits ("halluciner")
  • Remplacer votre jugement professionnel
❓
Questions fréquentes
Est-ce que ChatGPT lit mes conversations ?
Par défaut, OpenAI peut utiliser vos conversations pour améliorer son modèle. Vous pouvez désactiver cela dans les paramètres (voir Étape 2). Pour les données sensibles, n'entrez jamais rien dans ChatGPT.
ChatGPT peut-il se tromper ?
Oui, absolument. L'IA peut inventer des faits, des citations ou des statistiques ("hallucinations"). Relisez toujours et vérifiez les informations importantes avant de les utiliser.
La version gratuite suffit-elle ?
Pour les usages de base (rédaction, reformulation, quiz, résumés), la version gratuite (GPT-3.5 ou GPT-4o mini) est tout à fait suffisante. La version payante (20€/mois) permet d'utiliser GPT-4 avec des capacités plus avancées.
Puis-je utiliser ChatGPT pour mes cours ?
Oui, pour créer des contenus génériques (quiz, exercices, plans de cours, idées d'activités). Non, pour traiter des données réelles de stagiaires. Voir les 10 Règles d'Or RGPD.

Modèles de Prompts Direction

Compte-rendu · Courrier officiel · Note de service — prompts prêts à l'emploi

⚠ Règle d'or avant d'utiliser ces prompts Ne jamais inclure de données personnelles identifiantes (noms réels, IBAN, n° sécu…) dans un prompt envoyé à un outil cloud. Remplacer par [Prénom], [Service], [Montant], etc.

📝 Compte-rendu de réunion

Prompt 1 — CR formel à partir de notes
✘ Prompt insuffisant
"Écris un compte-rendu de réunion."
✔ Prompt optimisé
"Tu es assistant de direction pour [AUXILIA]. Voici les notes brutes d'une réunion du [DATE] réunissant [LISTE DES FONCTIONS : ex. DG, DRH, Responsable compta]. Rédige un compte-rendu formel en 3 parties : 1) Contexte et ordre du jour 2) Décisions prises 3) Actions à mener (responsable + délai). Ton professionnel, style concis, maximum 1 page A4."
→ Résultat : CR structuré exploitable en quelques secondes
Prompt 2 — CR à partir d'une transcription
✔ Prompt optimisé
"Tu es un assistant de direction expérimenté. Voici la transcription brute d'une réunion (données anonymisées). Produis : 1) Un résumé exécutif (5 lignes max) 2) Un tableau Actions/Responsables/Délais 3) Les points en suspens à l'ordre du jour suivant. Format : doc Word-friendly, titres en gras."
→ Résultat : synthèse directement utilisable pour le PV
Variables à remplacer : [DATE] [LISTE DES FONCTIONS] [Responsable X] [Délai]
💡 Astuce : Copier-coller vos notes directement après le prompt dans le même message. ChatGPT traitera le tout en une seule fois.

✉ Courrier officiel

Prompt 3 — Courrier de direction standard
✔ Prompt optimisé
"Rédige un courrier officiel de [AUXILIA] à [TYPE DE DESTINATAIRE : ex. partenaire, administration, prestataire] concernant [OBJET EN 1 PHRASE]. Ton : formel, bienveillant mais ferme. Formule de politesse appropriée. Points obligatoires à mentionner : [LISTE DES POINTS]. Signature : [Prénom NOM], [Fonction]."
→ Résultat : courrier complet à relire et personnaliser
Prompt 4 — Réponse à un courrier reçu
✔ Prompt optimisé
"Voici un courrier reçu [coller le texte anonymisé]. Rédige une réponse officielle de la part de [AUXILIA]. Notre position : [RÉSUMER EN 2 PHRASES]. Ton : professionnel, constructif. Inclure une proposition de suite concrète."
→ Résultat : réponse équilibrée, ton professionnel garanti

📌 Note de service interne

Prompt 5 — Note de service
✔ Prompt optimisé
"Rédige une note de service interne de [AUXILIA] à destination de [SERVICE / TOUS LES SALARIÉS]. Sujet : [OBJET]. Style : direct, clair, sans jargon. Format imposé : 1) Contexte (2 lignes) 2) Ce qui change / les consignes (liste à puces) 3) Date d'entrée en vigueur 4) Contact pour questions."
→ Résultat : note lisible, directement utilisable
Prompt 6 — Rappel de procédure / relance
✔ Prompt optimisé
"Rédige un rappel de procédure interne à [SERVICE] concernant [SUJET]. Ton bienveillant mais clair. Expliquer pourquoi c'est important (1 phrase), les étapes à respecter (numérotées), et les conséquences en cas de non-respect (sans être menaçant). Max 15 lignes."
→ Résultat : rappel non culpabilisant, efficace

💡 Conseils pour de meilleurs résultats

🎯 Rôle + contexte : Commencer par "Tu es [rôle]" aide l'IA à adopter le bon registre (direction, RH, juridique…)
📏 Contrainte de format : Indiquer "max 1 page", "liste à puces", "tableau" pour structurer le résultat
🔄 Itération : Si le résultat n'est pas satisfaisant, demander "Reformule en étant plus [concis / formel / chaleureux]" dans le même fil de conversation
🔒 RGPD : Remplacer systématiquement les noms réels, coordonnées et montants précis par des variables génériques avant d'envoyer à ChatGPT

RGPD & IA — Données sensibles

Ce qu'on ne dit jamais à l'IA · Checklist RGPD · Procédure d'alerte

🚦 Le feu tricolore des données

🔴 JAMAIS dans un outil IA cloud

  • Nom complet + coordonnées d'un salarié
  • Numéro de sécurité sociale
  • IBAN ou RIB
  • Données médicales ou handicap
  • Données disciplinaires personnelles
  • Identifiants de connexion
  • Stratégie commerciale confidentielle
  • Données financières du client non publiques

🟡 Avec précautions — évaluer

  • Données pseudonymisées (prénom uniquement)
  • Chiffres financiers agrégés sans lien à une personne
  • Situations RH anonymisées
  • Noms de projets internes non publics
  • Éléments de stratégie sans détail sensible

🟢 Sans risque — utiliser librement

  • Modèles de documents vierges
  • Textes génériques impersonnels
  • Structures de prompts sans données réelles
  • Reformulation de textes publics
  • Traductions de contenus non confidentiels
  • Création de formulaires vierges

✅ Checklist RGPD avant d'utiliser un outil IA

🚨 Procédure d'alerte en cas d'incident

Vous avez envoyé accidentellement des données sensibles à un outil IA cloud ? Agissez dans les 30 minutes. Toute violation de données personnelles doit être signalée à la CNIL dans les 72h si elle présente un risque pour les personnes concernées.
1Ne pas paniquer. Documenter immédiatement ce qui s'est passé (outil, heure, type de données, volume).
2Contacter le référent RGPD / DPO d'AUXILIA
3Supprimer les conversations de l'outil IA si l'interface le permet.
4Évaluer le risque avec le DPO : les personnes concernées doivent-elles être informées ?
5Notifier la CNIL si nécessaire (dans les 72h après détection) via notifications.cnil.fr

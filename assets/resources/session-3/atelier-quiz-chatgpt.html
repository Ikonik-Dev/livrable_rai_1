Exercice 1 — Créer une fiche de cours sur le RGPD

Objectif : générer une fiche structurée avec les bons paramètres dans le prompt

📋 Consignes
  1. Ouvrez ChatGPT (ou l'outil IA de votre choix)
  2. Rédigez un prompt pour créer une fiche de cours sur le RGPD (Règlement Général sur la Protection des Données)
  3. Public cible : salariés AUXILIA (aides à domicile, responsables de secteur)
  4. Durée de la séance : 1h30
  5. La fiche doit inclure : objectifs, plan, contenu essentiel, exercice pratique
  6. Évaluez le résultat : est-ce utilisable en formation ? Qu'est-ce qui manque ?
  7. Demandez une amélioration spécifique (ex : "Ajoute un exemple concret d'entreprise")
💡 Aide — Structure de prompt suggérée
Tu es formateur expert en droit du travail. Crée une fiche de cours sur le RGPD destinée à des salariés d'une structure d'aide à domicile (niveaux variés). Durée : 1h30. Inclure : 3 objectifs pédagogiques, plan avec horaires, 5 points clés à retenir, 1 exercice pratique (mis en situation), encadré "À retenir". Vocabulaire accessible, exemples issus du secteur médico-social.
⏱ 10 min 👤 Individuel 🖥 ChatGPT ou outil au choix

Points essentiels d'un bon prompt pour cet exercice

Tu es formateur expert en protection des données. Crée une fiche de cours sur le RGPD pour des salariés d'une association d'aide à domicile (niveaux CAP à Bac+2, publics variés). Durée : 1h30. Obligatoire : • 3 objectifs pédagogiques (formulation : "le stagiaire sera capable de…") • Plan horodaté (accueil 10 min, contenu 40 min, exercice 25 min, débrief 15 min) • 5 points clés à retenir (format encadré) • 1 mise en situation : "Marie, aide à domicile, reçoit une demande d'accès aux données d'un bénéficiaire…" • Vocabulaire simple, pas de jargon juridique non expliqué
Ce qui fait la différence :
  • Préciser le rôle de l'IA ("Tu es formateur expert")
  • Décrire le public avec précision (niveau, secteur)
  • Demander les éléments un par un (liste claire)
  • Proposer un exemple concret ancré dans le secteur
  • Préciser les contraintes de vocabulaire

Exercice 2 — Générer un quiz professionnel

Objectif : créer un quiz à 8 questions sur les gestes et postures, avec corrections

📋 Consignes
  1. Rédigez un prompt pour créer un quiz de 8 questions sur les gestes et postures (prévention des risques professionnels) pour des aides à domicile
  2. Format souhaité : QCM (4 propositions), avec la bonne réponse indiquée et une explication
  3. Intégrer au moins 2 niveaux de difficulté (basique + intermédiaire)
  4. Ensuite, demandez à l'IA : "Génère maintenant la version Kahoot de ce quiz" (format simplifié, durée par question)
  5. Comparez les deux versions — que gagne-t-on en spécifiant le format ?
💡 Aide — Prompt de départ
Génère un quiz de 8 questions sur les gestes et postures pour des aides à domicile (secteur aide à domicile). Public : niveau débutant à intermédiaire. Pour chaque question : • Formulation claire, vocabulaire terrain • 4 propositions (A/B/C/D), une seule bonne réponse • Bonne réponse indiquée + explication (2 lignes) • Niveau : ⭐ ou ⭐⭐ 6 questions niveau ⭐, 2 questions niveau ⭐⭐. Format tableau.

Exemple de prompt avancé — Quiz Gestes & Postures

Génère un quiz professionnel de 8 questions sur les gestes et postures pour prévenir les troubles musculo-squelettiques (TMS) chez les aides à domicile. Format : tableau avec colonnes N° / Question / A / B / C / D / Bonne réponse / Explication (2 lignes) / Niveau (⭐ ou ⭐⭐). • Questions 1 à 6 : niveau ⭐ (règles de base, vocabulaire courant) • Questions 7 et 8 : niveau ⭐⭐ (situations complexes, raisonnement) Contextualiser dans le quotidien de l'aide à domicile (transferts, portage, ménage, aide à la toilette).

Exercice 3 — Séquence pédagogique complète

Objectif : produire un package complet (plan + exercice + grille) sur un thème au choix

📋 Consignes
  1. En groupe de 2-3 personnes, choisissez un thème de formation lié à votre pratique (ex : hygiène, communication avec les familles, gestion du stress, protection de l'enfance…)
  2. En 3 prompts enchaînés, générez :
    • Prompt 1 : Plan de séance horodaté (1h30)
    • Prompt 2 : Sur la base de ce plan, crée 1 exercice pratique pour la séquence centrale
    • Prompt 3 : Pour cet exercice, crée une grille d'évaluation (5 critères, 3 niveaux)
  3. Évaluez : la cohérence entre les 3 éléments est-elle satisfaisante ? Qu'avez-vous dû corriger ?
  4. Partagez votre retour en grand groupe (2 min par équipe)
💡 Conseils pour cet exercice
Conseil 1 : Gardez le contexte entre les prompts → Dans le prompt 2, commencez par "Sur la base du plan de séance ci-dessus…" et collez le plan généré. Conseil 2 : Soyez précis sur la grille → Demandez des "descripteurs observables" (ce que l'évaluateur voit concrètement), pas des critères abstraits. Conseil 3 : Testez l'alignement pédagogique → Les objectifs du plan → l'exercice → la grille doivent évaluer la même compétence.

Exemple de chaîne de prompts — Thème : Communication avec les familles

PROMPT 1 — Plan de séance Génère un plan de séance de 1h30 sur "La communication bienveillante avec les familles de bénéficiaires" pour des aides à domicile expérimentés. Objectif : adapter sa communication en situation difficile. Format tableau : horaire / séquence / activité formateur / activité stagiaire / méthode / matériel.
PROMPT 2 — Exercice Sur la base du plan de séance ci-dessus, crée un exercice de jeu de rôle de 25 min pour la séquence "Mise en pratique". Scénario : une aide à domicile doit annoncer à une famille une dégradation constatée chez le bénéficiaire. Fiche formateur (briefing rôles) + fiche participant + consignes d'observation (3 critères).
PROMPT 3 — Grille Pour le jeu de rôle ci-dessus, crée une grille d'évaluation formative. 5 critères observables, 3 niveaux : En développement / Satisfaisant / Expert. Chaque niveau = description de ce qu'on observe concrètement. Format tableau.
Points de vigilance identifiés en formation :
  • L'IA peut générer des critères trop génériques ("communique bien") — demandez des indicateurs comportementaux observables
  • Vérifiez que l'exercice respecte bien la durée prévue dans le plan
  • Relire la grille en imaginant un apprenant réel — les descripteurs sont-ils réalistes ?

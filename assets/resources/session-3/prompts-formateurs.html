6 prompts prêts à l'emploi pour créer vos ressources pédagogiques avec l'IA

🎓 Session 3 — Formateurs 📅 12 novembre 2026
Comment utiliser cette fiche ?
Chaque prompt est un modèle. Remplacez les éléments entre crochets [comme ceci] par vos informations réelles. Vous pouvez ensuite demander des ajustements : "Simplifie le point 2", "Ajoute un exemple concret", "Adapte pour un apprenant débutant".
1

Fiche de cours complète Usage : préparer un nouveau module rapidement

❌ Trop vague
"Fais une fiche sur les gestes barrières."
✔ Prompt efficace
Tu es formateur expert en [domaine]. Crée une fiche de cours sur [sujet] pour un public de [public et niveau]. Durée : [durée]. Inclure obligatoirement : • 3 objectifs pédagogiques (formulation : « À l'issue de cette séance, le stagiaire sera capable de… ») • Plan structuré avec durées indicatives • Contenu essentiel (5 points clés max) • 1 exercice d'application pratique • Points à mémoriser absolument (encadré) Ton professionnel et accessible. Contextualiser au secteur [secteur].
→ Fiche complète et structurée en moins de 1 minute. Relisez et adaptez au contexte terrain de vos apprenants.
2

Quiz QCM engageant Usage : évaluation diagnostique ou formative

❌ Insuffisant
"Fais des questions sur le RGPD."
✔ Prompt efficace
Génère un quiz de [N] questions sur [sujet] pour évaluer [compétence cible]. Public : [public]. Pour chaque question : • Formulation claire et sans ambiguïté • 4 propositions (A/B/C/D), une seule bonne réponse • Indiquer la bonne réponse • Explication de la bonne réponse (2 lignes max) • Niveau : ⭐ basique / ⭐⭐ intermédiaire / ⭐⭐⭐ avancé Format tableau. Adapter le vocabulaire au secteur de l'aide à domicile.
→ Quiz prêt à intégrer dans Kahoot, Wooclap, ou à imprimer. Vérifiez l'exactitude des réponses avant utilisation.
3

Plan de séance horodaté Usage : structurer une session de 1h à 3h

✔ Prompt efficace
Génère un plan de séance de formation de [durée] sur [sujet]. Public : [public et niveau]. Objectif principal : [objectif]. Pour chaque séquence, indiquer : • Horaire et durée • Titre de la séquence • Activité formateur (ce que je fais) • Activité stagiaire (ce qu'il fait) • Méthode pédagogique (exposé / question-réponse / exercice / jeu de rôle…) • Matériel nécessaire Format tableau. Inclure accueil, contenu, pratique, débrief, clôture.
→ Plan utilisable directement comme guide d'animation. Ajoutez vos anecdotes et exemples terrain.
4

Différenciation pédagogique Usage : adapter une ressource existante

✔ Prompt efficace
Voici [un exercice / une fiche / une consigne] : [Coller le contenu existant] Adapte ce contenu en 3 versions : 1. Version FACILE : pour un apprenant en difficulté ou débutant (vocabulaire simple, étapes guidées, exemples concrets) 2. Version STANDARD : niveau attendu normal 3. Version AVANCÉE : pour un apprenant rapide (plus autonome, aller plus loin) Conserver le même objectif pédagogique pour les 3 versions.
→ 3 versions en 1 prompt. Idéal pour les groupes hétérogènes ou les formations en autonomie.
5

Mise en situation réaliste Usage : ancrer l'apprentissage dans le réel

✔ Prompt efficace
Crée une mise en situation professionnelle pour illustrer [compétence] dans le secteur [secteur]. Structure : • Contexte (5 lignes) : lieu, personnes impliquées, situation • Rôles : ce que fait le formateur, ce que fait l'apprenant • Consignes claires pour l'apprenant • 3 questions de débrief pour le formateur • Points d'attention pédagogiques Durée de l'activité : [durée]. Ton réaliste, ancré dans le quotidien professionnel.
→ Scénario immédiatement utilisable. Modifiez les noms et détails pour correspondre à votre contexte.
6

Feedback et grille d'évaluation Usage : évaluer une production ou compétence

✔ Prompt efficace
Crée une grille d'évaluation pour évaluer [compétence ou production attendue]. Inclure : • 5 critères d'évaluation clairs et observables • 3 niveaux par critère : Insuffisant / En développement / Maîtrisé • Descripteurs concrets pour chaque niveau (ce qu'on observe) • Pondération suggérée si pertinent Format tableau. Ensuite, crée un modèle de feedback écrit de 3-5 lignes : 1 point fort, 1 axe d'amélioration, 1 conseil concret.
→ Grille + modèle de feedback prêts à personnaliser. Vérifiez l'alignement avec vos objectifs pédagogiques.
